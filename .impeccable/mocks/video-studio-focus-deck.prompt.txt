Use case: ui-mockup
Asset type: high-fidelity desktop application composition study for Mental Empire Studio's Video Studio
Primary request: Design composition option C, "Focus deck," for a professional lightweight nonlinear video editor used by independent faceless-YouTube creators.
Surface structure, in order: one compact 58px command bar with project identity, format, timecode, undo/redo, saved state, Fast preview and Render; beneath it an upper workspace where a narrow 190px media shelf uses one-column visual thumbnails at left, a very large uncluttered video stage fills the center, and a 300px contextual inspector at right uses a calm vertical mode index with Media, Captions, Motion, Color, Audio, Export; beneath the preview is a precise transport strip; the bottom 32% is a full-width timeline with fixed track headers, toolbar, ruler, caption phrase clips, image-rich Auto B-roll, visual overlays and narration waveform.
Real UI content: title "Video Studio", project "The Discipline of Focus", "1920 × 1080", "30 fps", timecode "00:01:42:18"; actions "Fast preview", "Render"; tracks Captions, Auto B-roll, Visuals, Audio.
Visual system: established Creator Control Room. Near-black #070809, graphite #0d0f14, charcoal #12151b and inset #0e1116, crisp quiet dividers #1d2129, strong text #f4f6f9, secondary #aab0bb. Use signal amber #f5b323 only for the selected clip, current mode and Render; use emerald only for Saved. Compact Space Grotesk-like headings, readable Hanken Grotesk-like UI text, JetBrains Mono-like time data.
Signature: a tiny amber current-edit notch at the preview edge aligns exactly with the selected timeline clip and the inspector's active section, forming one restrained edit spine. Everything else is neutral.
Style/medium: premium flat desktop product UI screenshot; visually light despite dense capability; strong negative space around the stage; tonal depth, 1px lines, restrained 8-10px corners, minimal shadows.
Composition/framing: straight-on edge-to-edge 16:9 desktop interface, no device frame, no people, no desk.
Constraints: preserve familiar editing affordances, all visible tools and modes remain accessible, realistic active edit, preview media is a cinematic mountain landscape with clean bold white captions.
Avoid: dashboard or bento cards, neon, cyberpunk, purple, glass, glossy 3D, decorative gradients, excess glow, giant type, floating pills, rounded-everything, fake metrics, landing page, poster composition, Adobe/Premiere/DaVinci branding, watermark.
