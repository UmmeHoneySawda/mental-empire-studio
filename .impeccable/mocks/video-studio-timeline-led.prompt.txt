Use case: ui-mockup
Asset type: high-fidelity desktop application composition study for Mental Empire Studio's Video Studio
Primary request: Design composition option B, "Timeline-led cut table," for a professional lightweight nonlinear video editor used by faceless-YouTube creators.
Surface structure, in order: a compact 56px project command bar; an upper workbench occupying 56% of the surface with a slim 76px vertical tool rail at far left, a 250px searchable media filmstrip beside it, a large centered 16:9 preview, and a 310px inspector on the right; a visually dominant lower timeline occupying 40% with a clear tool strip, fixed track headers, time ruler, caption phrase blocks, B-roll thumbnail clips, visual overlays, narration waveform and a single red playhead.
Real UI content: title "Video Studio", project "The Discipline of Focus", format "1920 × 1080", "30 fps", timecode "00:01:42:18", actions "Fast preview" and "Render"; inspector modes Media, Captions, Motion, Color, Audio, Export; timeline tracks Captions, Auto B-roll, Visuals, Audio.
Visual system: established Creator Control Room. Control-room black #070809, window graphite #0d0f14, panel charcoal #12151b, inset #0e1116, quiet dividers #1d2129, strong text #f4f6f9, soft text #cdd2da, secondary #aab0bb, one restrained signal amber #f5b323 for current edit and primary action, success emerald only for saved state. Compact Space Grotesk-like headings, highly readable Hanken Grotesk-like UI text, JetBrains Mono-like timecodes.
Signature: the timeline is an inlaid precision surface with a narrow amber selection channel running from the chosen B-roll clip upward to a small current-edit label above the preview. This functional seam is the only accent gesture.
Style/medium: premium flat desktop product UI screenshot, dense, exact, calm, understated, crisp 1px structure, restrained 8-10px corners, tonal rather than shadow-heavy depth.
Composition/framing: straight-on 16:9 landscape, edge-to-edge app interface, no device frame, no human, no desk.
Constraints: familiar editor affordances, preserve visible tools and states, large usable timeline, realistic active edit, preview media is a cinematic mountain silhouette with bold white caption text.
Avoid: dashboard cards, bento layout, neon cyberpunk, purple, glassmorphism, glossy 3D, gradients as decoration, excessive glow, oversized type, floating pills, rounded-everything, fake metrics, landing page, poster, Adobe/Premiere/DaVinci branding, watermark.
