Use case: ui-mockup
Asset type: high-fidelity desktop application composition study for Mental Empire Studio's Video Studio
Primary request: Design a professional, lightweight nonlinear video editor interface for independent faceless-YouTube creators. This is composition option A, "Stage-led cut table."
Surface structure, in order: a compact 56px project command bar across the top; below it a 220px media shelf on the left, a dominant central video preview occupying roughly 55% of the upper work area, and a 320px contextual inspector on the right; a full-width precision timeline occupies the lower 34% with track headers, ruler, clips, audio waveform, playhead, zoom and editing tools.
Real UI content: title "Video Studio", project "The Discipline of Focus", format "1920 × 1080", "30 fps", timecode "00:01:42:18", actions "Fast preview" and "Render"; inspector tabs Media, Captions, Motion, Color, Audio, Export; timeline tracks Captions, Auto B-roll, Visuals, Audio.
Visual system: established Creator Control Room. Near-black graphite background #070809, window graphite #0d0f14, panel charcoal #12151b, quiet dividers #1d2129, strong text #f4f6f9, secondary #aab0bb, one restrained signal amber #f5b323 only for current selection and primary action, status emerald only for saved/healthy state. Space Grotesk-like compact headings, Hanken Grotesk-like readable interface text, JetBrains Mono-like timecode/data.
Signature: the selected timeline clip, playhead, and inspector header share one precise amber focus seam so the current edit reads as a connected decision, not decoration.
Style/medium: flat high-end product UI screenshot, dense but calm, crisp 1px structure, tonal depth, restrained 8-10px corners, no glossy 3D.
Composition/framing: straight-on landscape desktop app surface, 16:9, edge-to-edge interface, no device frame, no human, no surrounding desk.
Constraints: preserve familiar editor affordances and every visible feature; highly legible hierarchy; lightweight density; a realistic active edit state; the preview shows a cinematic mountain silhouette frame with bold white captions only as media content.
Avoid: bento-card dashboard, neon cyberpunk, purple, glassmorphism, giant typography, excessive gradients, excessive glow, floating capsules, rounded-everything, fake analytics, marketing landing page, poster composition, Adobe/Premiere/DaVinci branding, watermark.
